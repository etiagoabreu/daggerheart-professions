New Homebrew Cards for Professions, created using the Daggerheart Homebrew Kit and following the DPCGL license.

How to use: 
1. Change the Homebrew setting to allow 3 domains.
2. Create the player character sheet normally.
3. Open the Class section on the player character sheet and change it to the desired Domain.

> Rule: The goal of this homebrew is to give characters identity outside of combat. A character is no longer just “the warrior” or “the mage.” Now they can also be the group’s blacksmith, the expert alchemist, and soon much more. Each profession contains a set of 25 cards focused on that profession. Throughout the adventure, the hero decides whether to improve their professional abilities or their combat abilities.

Available Profissions: 
- Alchemist (25 new cards)
- Blacksmith (25 new cards) (in development)

Many more coming soon.

## Instalation

FoundryVTT:

1. Open **Add-on Modules**
2. Click on **Install Module**
3. Paste the Manifest URL:

```txt
https://github.com/etiagoabreu/daggerheart-professions/releases/latest/download/module.json
```
